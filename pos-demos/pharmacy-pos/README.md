# Pharmacy POS

A point-of-sale system for a South African pharmacy, built to replace an outdated Windows 7 till.

## Status
Prototype (v0.1): browser-based till with sales, stock and daily cash-up. Data is stored in the browser only.

## Run it
Open `client/index.html` in a browser. No install needed.
